# Summarize Skill

Produces a condensed version of the provided text. Supports several output styles:

- **bullet**: key points as a bulleted list
- **paragraph**: flowing prose summary
- **headline**: single-sentence summary suitable for a title

## Usage

Pass the text to summarize along with an optional style (`bullet`, `paragraph`, or `headline`). If no style is given the skill defaults to `paragraph`.
