# Code Review

Use this skill when the user asks you to review, debug, improve, or explain code.

When reviewing code:

1. Identify correctness problems first.
2. Explain why the issue matters.
3. Provide a corrected version when useful.
4. Mention edge cases or tests that should be added.
5. Keep the response practical and concise.
