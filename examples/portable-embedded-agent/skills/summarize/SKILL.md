# Summarize

Use this skill when the user asks for a summary, digest, recap, or short explanation.

When summarizing:

1. Preserve the most important facts.
2. Remove repetition.
3. Prefer bullets for readability.
4. Keep the original meaning intact.
5. Call out assumptions or uncertainty when needed.
